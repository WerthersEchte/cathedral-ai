## About
This is a Java interface for playing the implementation of the board game cathedral (https://en.wikipedia.org/wiki/Cathedral_(board_game)) with an ai.

## How to get
Add to gradle:
```
implementation 'io.github.werthersechte:cathedral-ai:2.0.0'
```

Add to maven:
```
 <dependency>
    <groupId>io.github.werthersechte</groupId>
    <artifactId>cathedral-ai</artifactId>
    <version>2.0.0</version>
 </dependency>
```
